ഭാഗം 1 · SEO
Tool 01 · Google

Google Search Console

Website ഏത് keywords-ന് rank ചെയ്യുന്നു എന്ന് കാണാം Free

നമ്മുടെ website ഏതൊക്കെ keywords-നാണ് Google-ൽ rank ചെയ്യുന്നത്, എത്ര clicks ലഭിക്കുന്നു, website-ൽ എന്തൊക്കെ technical issues ഉണ്ട് എന്നെല്ലാം അറിയാൻ സഹായിക്കുന്ന tool.

Google Search Console തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • ആളുകൾ ഏത് വാക്കുകൾ search ചെയ്തിട്ടാണ് നിങ്ങളുടെ site-ൽ എത്തുന്നത് എന്ന് കാണാം
  • ഏതൊക്കെ pages Google index ചെയ്തു, ഏതൊക്കെ ചെയ്തിട്ടില്ല എന്ന് നോക്കാം
  • Sitemap submit ചെയ്യാം, പുതിയ page index ചെയ്യാൻ request ചെയ്യാം

ആർക്ക് ഉപകാരപ്പെടും

Website ഉള്ള എല്ലാവർക്കും. SEO തുടങ്ങുമ്പോൾ ആദ്യം set ചെയ്യേണ്ട tool ഇതാണ്.

അറിയേണ്ടത്: Website നിങ്ങളുടേതാണെന്ന് verify ചെയ്യണം. Data കാണിച്ചുതുടങ്ങാൻ കുറച്ച് ദിവസം എടുക്കും.

കൂടുതൽ: Google Search Console for beginners (ബ്ലോഗ്, English)

Tool 02 · Microsoft

Bing Webmaster Tools

Bing search-ലെ performance, Search Console-ൽ നിന്ന് import ചെയ്യാം Free

Google Search Console പോലെ തന്നെ Bing search-ൽ website-ന്റെ performance പരിശോധിക്കാം. മാത്രമല്ല, Search Console-ൽ നിന്ന് നേരിട്ട് നമ്മുടെ website import ചെയ്യാനും കഴിയും.

Bing Webmaster Tools തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • Bing-ൽ നിന്നുള്ള clicks, impressions, keywords എന്നിവ കാണാം
  • Search Console-ൽ നിന്ന് site import ചെയ്താൽ വീണ്ടും verify ചെയ്യേണ്ട
  • Sitemap submit ചെയ്ത് Bing-ൽ pages വേഗത്തിൽ വരാൻ സഹായിക്കാം

ആർക്ക് ഉപകാരപ്പെടും

Google-ൽ Search Console set ചെയ്ത എല്ലാ website ഉടമകൾക്കും. കുറച്ച് മിനിറ്റ് മതി.

അറിയേണ്ടത്: പല websites-നും Bing-ൽ നിന്നുള്ള traffic Google-നേക്കാൾ കുറവായിരിക്കും. എങ്കിലും setup എളുപ്പമായതിനാൽ ചെയ്തുവെക്കുന്നത് നല്ലതാണ്.

Tool 03 · Screaming Frog

Screaming Frog SEO Spider

Website-ന്റെ complete technical SEO audit Free

Website-ന്റെ complete SEO audit ചെയ്യാൻ പറ്റിയ tool. Broken links, missing titles, duplicate pages തുടങ്ങി നിരവധി technical SEO issues കണ്ടെത്താം. Free version-ൽ 500 URLs വരെ crawl ചെയ്യാം.

Screaming Frog SEO Spider തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • Broken links (404 pages) കണ്ടെത്താം
  • Title, meta description, H1 എന്നിവ ഇല്ലാത്തതോ duplicate ആയതോ ആയ pages കാണാം
  • എല്ലാ pages-ന്റെയും list export ചെയ്ത് Excel-ലോ Google Sheets-ലോ പരിശോധിക്കാം

ആർക്ക് ഉപകാരപ്പെടും

ചെറിയ-ഇടത്തരം websites-ന്റെ audit ചെയ്യുന്നവർക്ക്. 500 URLs-ൽ താഴെയുള്ള site ആണെങ്കിൽ free version മതി.

അറിയേണ്ടത്: ഇത് computer-ൽ install ചെയ്യേണ്ട software ആണ്, website അല്ല. 500 URLs-ൽ കൂടുതൽ pages ഉണ്ടെങ്കിൽ paid licence വേണം.

Tool 04 · Neil Patel

Ubersuggest

Keyword research, search volume, competitor keywords Free

Keyword research ചെയ്യാനും search volume അറിയാനും competitors ഏതൊക്കെ keywords ഉപയോഗിക്കുന്നു എന്ന് കണ്ടെത്താനും സഹായിക്കും. Free version-ൽ searches limited ആണ്.

Ubersuggest തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • ഒരു keyword-ന്റെ search volume-ഉം difficulty-യും നോക്കാം
  • അതിനോട് ബന്ധപ്പെട്ട പുതിയ keyword ideas കിട്ടും
  • Competitor website ഏതൊക്കെ keywords-ന് rank ചെയ്യുന്നു എന്ന് കാണാം

ആർക്ക് ഉപകാരപ്പെടും

Blog topics-ഉം service pages-ന്റെ keywords-ഉം തിരഞ്ഞെടുക്കുന്നവർക്ക്.

അറിയേണ്ടത്: Free version-ൽ ഒരു ദിവസം ചെയ്യാവുന്ന searches limited ആണ്. Volume numbers ഏകദേശ കണക്കാണ്, exact അല്ല.

Tool 05 · AnswerThePublic

AnswerThePublic

ആളുകൾ ഒരു topic-നെക്കുറിച്ച് എന്തൊക്കെ ചോദിക്കുന്നു Free

നമ്മുടെ audience ഒരു particular topic-നെക്കുറിച്ച് എന്തൊക്കെയാണ് ചോദിക്കുന്നത് എന്ന് കണ്ടെത്താം. Blog topics, content ideas, Reels എന്നിവയ്ക്ക് വളരെ useful ആണ്. Free version-ൽ usage limited ആണ്.

AnswerThePublic തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • ഒരു keyword type ചെയ്താൽ ആളുകൾ ചോദിക്കുന്ന questions കിട്ടും (what, how, why, can…)
  • ആ questions blog headings ആയോ FAQ ആയോ ഉപയോഗിക്കാം
  • Reels, YouTube videos എന്നിവയ്ക്കുള്ള topics-ഉം ഇവിടെ നിന്ന് കിട്ടും

ആർക്ക് ഉപകാരപ്പെടും

Content ഉണ്ടാക്കുന്നവർക്ക്: blog, Reels, YouTube.

അറിയേണ്ടത്: Free version-ൽ usage limited ആണ്. ചോദ്യങ്ങൾ search suggestions-ൽ നിന്നാണ് വരുന്നത്, അതിനാൽ ഏതൊക്കെ എഴുതണം എന്ന് നിങ്ങൾ തന്നെ തിരഞ്ഞെടുക്കണം.

ഭാഗം 2 · Ads research
Tool 06 · Meta

Meta Ad Library

Competitors Facebook-ലും Instagram-ലും run ചെയ്യുന്ന ads Free

നിങ്ങളുടെ competitors Facebook-ലും Instagram-ലും ഏതൊക്കെ advertisements ആണ് run ചെയ്യുന്നത് എന്ന് നേരിട്ട് കാണാം. അവരുടെ creatives, offers, ad messaging എന്നിവ പഠിക്കാൻ ഏറ്റവും നല്ല tool.

Meta Ad Library തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • ഒരു brand-ന്റെ Page name search ചെയ്ത് അവരുടെ active ads കാണാം
  • Image, video, ad copy, button എന്നിവ നോക്കി ഏത് offer ആണ് അവർ പറയുന്നത് എന്ന് മനസ്സിലാക്കാം
  • ഒരു ad എപ്പോൾ മുതൽ run ചെയ്യുന്നു എന്ന തീയതി കാണാം

ആർക്ക് ഉപകാരപ്പെടും

Meta Ads ചെയ്യുന്നവർക്കും ഒരു പുതിയ business-ന് ads ഐഡിയ വേണ്ടവർക്കും.

അറിയേണ്ടത്: ഒരു ad എത്ര രൂപ spend ചെയ്തു, എത്ര results കിട്ടി എന്നൊന്നും സാധാരണ ads-ന് ഇവിടെ കാണിക്കില്ല. Idea എടുക്കാൻ ഉപയോഗിക്കുക, അതേപടി copy ചെയ്യരുത്.

Tool 07 · Google

Google Ads Transparency Center

Brands Google-ൽ കാണിക്കുന്ന ads Free

Google-ന്റെ സ്വന്തം ad library. വിവിധ brands Google Search, YouTube തുടങ്ങിയ Google platforms-ൽ കാണിക്കുന്ന advertisements ഇവിടെ പരിശോധിക്കാം.

Google Ads Transparency Center തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • Advertiser name അല്ലെങ്കിൽ website search ചെയ്ത് അവരുടെ ads കാണാം
  • Text, image, video എന്നിങ്ങനെ ad format അനുസരിച്ച് filter ചെയ്യാം
  • Country / region തിരഞ്ഞെടുത്ത് അവിടെ കാണിക്കുന്ന ads നോക്കാം

ആർക്ക് ഉപകാരപ്പെടും

Google Ads ചെയ്യുന്നവർക്ക്. Competitor ഏത് ad copy ആണ് ഉപയോഗിക്കുന്നത് എന്ന് അറിയാൻ.

അറിയേണ്ടത്: ഇവിടെയും ads-ന്റെ results (clicks, cost) കാണില്ല. Region filter ശരിയാക്കിയില്ലെങ്കിൽ ആവശ്യമുള്ള ads വരില്ല.

Tool 08 · LinkedIn

B2B competitors LinkedIn-ൽ run ചെയ്യുന്ന ads Free

പ്രത്യേകിച്ച് B2B marketers ശ്രദ്ധിക്കേണ്ട tool. Competitors LinkedIn-ൽ run ചെയ്യുന്ന advertisements, creatives, messaging എന്നിവ പഠിക്കാം.

LinkedIn Ad Library തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • B2B competitors ഏത് ആളുകളോടാണ് സംസാരിക്കുന്നത് (ഏത് offer, ഏത് message) എന്ന് മനസ്സിലാക്കാം
  • Lead magnet, webinar, case study തുടങ്ങിയ ads-ന്റെ ideas കിട്ടും

ആർക്ക് ഉപകാരപ്പെടും

B2B service companies-ന്റെ marketing ചെയ്യുന്നവർക്ക്.

അറിയേണ്ടത്: Leads, cost തുടങ്ങിയ performance data ഇവിടെ കാണിക്കില്ല. Competitor-ന്റെ message പഠിക്കാൻ മാത്രം ഉപയോഗിക്കുക.

Tool 09 · Google Ads

Microsoft Clarity തുറക്കുക

എന്തിന് ഉപയോഗിക്കാം

  • Heatmap-ൽ ഏത് button-ൽ കൂടുതൽ click വരുന്നു, ഏത് ഭാഗം ആരും കാണുന്നില്ല എന്ന് കാണാം

  • Contact form-ൽ ആളുകൾ എവിടെ വെച്ച് നിർത്തുന്നു എന്ന് കണ്ടെത്താം

ആർക്ക് ഉപകാരപ്പെടും

Landing page, contact page എന്നിവയുടെ conversion കൂട്ടാൻ ആഗ്രഹിക്കുന്നവർക്ക്.

അറിയേണ്ടത്: Website-ൽ Clarity code ചേർക്കണം. Visitors-നെ record ചെയ്യുന്നതിനാൽ privacy policy / cookie notice പുതുക്കണം. Form-ൽ ആളുകൾ type ചെയ്യുന്ന വ്യക്തിഗത വിവരങ്ങൾ mask ചെയ്യാനുള്ള setting ശ്രദ്ധിക്കണം.

Digital marketing പഠിക്കാൻ ഏതൊക്കെ free tools ഉണ്ട്?

SEO-ക്ക് Google Search Console, Bing Webmaster Tools, Screaming Frog, Ubersuggest, AnswerThePublic. Ads research-ന് Meta Ad Library, Google Ads Transparency Center, LinkedIn Ad Library, Google Keyword Planner, Google Trends. ഈ tools ശരിക്കും free ആണോ?

എല്ലാം free ആയി തുടങ്ങാം. Search Console, Bing Webmaster Tools, Meta Ad Library, Google Ads Transparency Center, LinkedIn Ad Library, Google Trends, GA4, Clarity, Looker Studio, PageSpeed Insights എന്നിവ സൗജന്യമാണ്. Screaming Frog (500 URLs വരെ), Ubersuggest, AnswerThePublic, Canva എന്നിവയ്ക്ക് free version-ൽ പരിധികൾ ഉണ്ട്, കൂടുതൽ വേണമെങ്കിൽ paid plan വേണം. Keyword Planner ഉപയോഗിക്കാൻ ഒരു Google Ads account വേണം.

SEO തുടങ്ങാൻ ആദ്യം ഏത് tool ഉപയോഗിക്കണം?

Google Search Console. നിങ്ങളുടെ website ഏത് keywords-ന് Google-ൽ കാണിക്കുന്നു, എത്ര clicks കിട്ടുന്നു, index ആയോ എന്നെല്ലാം അതിൽ കാണാം. അതിന് ശേഷം Bing Webmaster Tools set ചെയ്യുക, പിന്നെ Screaming Frog കൊണ്ട് site audit ചെയ്യുക.

Competitors-ന്റെ ads എങ്ങനെ കാണാം?

Facebook, Instagram ads-ന് Meta Ad Library, Google Search, YouTube ads-ന് Google Ads Transparency Center, B2B ads-ന് LinkedIn Ad Library ഉപയോഗിക്കാം. Brand-ന്റെ പേര് search ചെയ്താൽ അവർ run ചെയ്യുന്ന ads കാണാം. എത്ര spend ചെയ്തു, എത്ര results കിട്ടി എന്ന് സാധാരണ ഇവിടെ കാണില്ല.

Keyword research free ആയി എങ്ങനെ ചെയ്യാം?

Google Keyword Planner, Ubersuggest (free version-ൽ searches limited), AnswerThePublic എന്നിവ ഉപയോഗിക്കാം. Google Trends കൊണ്ട് ഏത് keyword-ന് interest കൂടുന്നു എന്ന് താരതമ്യം ചെയ്യാം. Volume numbers എല്ലാം ഏകദേശ കണക്കുകളാണ്, അതിനാൽ ഒരു tool മാത്രം വിശ്വസിക്കരുത്.

Website speed എങ്ങനെ check ചെയ്യാം?
