The basics

What is Google Tag Manager?

If this is your first time hearing about it, start here.

01

It is a delivery system for tracking codes

Your website needs tracking codes to send data to platforms like Google Analytics, Google Ads and Meta. GTM lets you manage all these codes from one dashboard instead of editing your website every time.

02

You install GTM once, then manage everything from its dashboard

You add a small piece of GTM code to your website one time. After that, you add, edit or remove tracking codes from GTM's web interface. No need to touch the website code again for most changes.

03

It reduces your dependence on developers

Without GTM, every small tracking change means asking a developer to edit the website. With GTM, marketers can handle most tracking changes themselves. You still need a developer for the initial GTM installation and some advanced setups.

04

It is free

Google Tag Manager is completely free. The platforms you connect (Google Ads, Meta Ads) have their own costs, but GTM itself costs nothing.

Three things to understand in GTM.

Tag

The tracking code you want to run.

ExampleSend a "form_submit" event to Google Analytics when someone fills the contact form.

Trigger

When should this tag fire?

ExampleWhen someone clicks the WhatsApp button on any page.

Variable

Extra details about the action.

ExampleWhich page was the person on? What link did they click?

Questions

Common doubts.

What is Google Tag Manager?

Google Tag Manager (GTM) is a free tool from Google that lets you manage tracking codes (called tags) on your website without editing the website code every time. You install GTM once, and then add or change tracking for Google Analytics, Google Ads, Meta Pixel and other platforms from GTM's dashboard.

Is Google Tag Manager free?

Yes. Google Tag Manager is completely free to use. The platforms you connect through it, such as Google Ads or Meta Ads, have their own costs, but GTM itself costs nothing.

Do I need GTM if I already have Google Analytics?

GA4 can be installed directly without GTM, and it tracks basic things like page views, scrolls and outbound clicks automatically with Enhanced Measurement. But GTM makes it easier to add custom event tracking (like form submissions or button clicks) and to manage tags for multiple platforms (Google Ads, Meta Pixel) from one place. For a simple website with only GA4, you may not need GTM. For anything with paid ads or custom tracking, GTM saves time.

What is the difference between a tag, a trigger and a variable in GTM?

A tag is the tracking code you want to run, like sending an event to Google Analytics. A trigger is the condition that decides when the tag runs, like when someone clicks a button. A variable is extra information about that action, like which page the click happened on or what link was clicked.

Should I install GTM before or after Google Analytics?

If you plan to use GTM, set it up first, then add Google Analytics as a tag inside GTM. That way all your tracking goes through one system. If you already installed GA4 directly on your site, you can switch to GTM later, but remove the direct GA4 code first so you don't double-count.
