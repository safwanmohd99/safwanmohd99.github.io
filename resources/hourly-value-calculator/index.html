എങ്ങനെ calculate ചെയ്തു?

മാസ ശമ്പളം (Monthly):

Hourly value = മാസ ശമ്പളം ÷ (ജോലി ദിവസങ്ങൾ × ജോലി മണിക്കൂറുകൾ)

Paid leave ആണെങ്കിൽ, ശമ്പളം മാറില്ല, പക്ഷേ ജോലി ദിവസങ്ങൾ കുറയും — അതുകൊണ്ട് hourly value കൂടും.

Unpaid leave ആണെങ്കിൽ, leave ദിവസങ്ങളുടെ ശമ്പളം cut ആകും.

ദിവസ കൂലി (Daily):

Hourly value = ദിവസ കൂലി ÷ ജോലി മണിക്കൂറുകൾ

യാത്ര സമയം:

യാത്ര സമയം കൂടി കൂട്ടിയാൽ: മാസ ശമ്പളം ÷ (ജോലി ദിവസങ്ങൾ × (ജോലി + യാത്ര മണിക്കൂറുകൾ))
